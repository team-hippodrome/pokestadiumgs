# Model setup in 6E850

## `func_8006E1C8`

This 264-byte owner resolves its first four pointer words through
`Memmap_GetSegmentVaddr` and resolves the fifth when nonnull. It installs
the second pointer as `D_80128C70`, copies eight words from the fourth
pointer to destination offset 8, writes one to the destination's first
halfword, and points destination offset 4 at the copied block. The copied
fields retain unknown names. It builds `D_80129038` through `guScale`, then
calls `func_8006DEBC(destination, third_pointer, fifth_pointer)` and
`func_8006F23C(destination)`.

`func_8007087C` supplies all five pointer arguments after preparing the
model's matrices. The existing `VertexNormalCounter` declaration and its
consumer `func_8006E2F8` establish the type behind `D_80128C70`; moving that
type earlier permits its reuse. Original `func_8006DEBC` consumes three
pointer words, including the saved second pointer and the third pointer
used by its vertex transforms. `func_8006E2D0` now declares and explicitly
forwards those three incoming pointers before calling `func_8006F23C`.
All ten of that existing wrapper's words and its 24-byte frame remain exact.
//@src/6E850.c

`Memmap_GetSegmentVaddr` takes and returns an unsigned word, resolving
segmented addresses through the current segment map. The replacement
retains that interface with explicit pointer/word casts.
//@src/2CA0.c

The scale word at `D_800A5960` is retail `0x3DCCCCCD` (0.1f), in the
existing read-only blob at ROM `0xA6560`. Its external declaration keeps
that data ownership. Capturing the value before the model writes reproduces
the observed load order. The libultra `guScale` interface takes a matrix
pointer followed by three floats. No storage, fake, padding, instruction
rewrite or data-layout change is introduced.
//@lib/ultralib/src/gu/scale.c
