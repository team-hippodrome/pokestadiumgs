## func_800739EC: requeue (2026-10-28)

EUC/JIS to Shift-JIS string converter `u8 *f(u8 *src, u8 *dst)`. If `dst` is
NULL it falls back to `D_8012B410` (bss, not yet declared anywhere), and it
returns `dst`. Best is 0.70 normalized:

```c
while ((c = *src++) != 0) {
    hi = c;
    if (c < 0x80) { *out++ = c; }
    else {
        lo = *src++;            /* u8 */
        hi &= 0x7F;
        if (lo == 0) break;
        lo &= 0x7F;
        if (hi & 1) { add = (lo < 0x60) ? 0x1F : 0x20; /* as if/else */ }
        else add = 0x7E;
        lo += add;
        base = (hi < 0x5F) ? 0x71 : 0xB1;   /* as if/else */
        out[0] = base + (hi - 1) / 2; out[1] = lo; out += 2;
    }
}
*out = 0; return dst;
```

Remaining diffs:
- Retail loads the lead byte into `a2` and copies it to `v0` in the `slti`
  delay slot. Ours loads into `v0`.
- The odd/`>= 0x60` path materializes 0x20 in `a3` (lo's register, with lo
  copied to `t0` first), then moves it to `v0`.
- The `base` constants land in `t0`, and the high byte is summed into `v0`.

Already tried without gain:
- widths u8/s32/u32/s16 for `c`, `hi` and `lo`
- `for` and `*src`-test loop forms
- `c = hi & 0x7F` reassignment
- ternaries for `add` and `base`
- `add++` and `lo >= 0x7F` formulations
- a shared `add`/`base` temp
- 300 s of permuter (no structural gain)

Next hypothesis: parameter reuse (as in `func_80033F74`), e.g. `dst`/`src` reused
as the cursor, or a `u8 *` output cursor that *is* `dst`, with the return value
