frame 8. It selects a table from the 0x14-byte records starting at
`D_88A01C30 + 0x20` and picks an `s16` index by mode: 0 → +0x16 and

**typed record arrays** (`unk_D_88A01C30_20` at `+0x20`, `unk_D_88234720`).

and swaps temps (0.51–0.62), and a 0x24-byte overlay with the table at +0x20
changes the stride.
