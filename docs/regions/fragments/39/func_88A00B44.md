# Grouped entry-list save buffer

`func_88A00B44` converts the main grouped list into the save buffer passed
to `Deck_WriteEntries` by `func_88A01990`. The input has group counts at
bytes 1 through 4, starting indices at bytes 5 through 8, and two-byte
rows at byte 9. This is the layout produced by `func_88A00978`.

The first group is copied to output byte 58 with its count at byte 57
and a first-byte `0xFF` terminator. When `func_8800005C` is nonzero,
the other counts and the 57-byte value table are cleared, and the
remaining lists receive terminators. Otherwise, the second group is
copied to byte 127 with its count at byte 126. The third group's rows
are expanded into bytes 0 through 56 by comparing their identifiers
with `D_88A01B80`; absent identifiers produce zero. The fourth group's
first bytes are copied to byte 100 with its count at byte 99. Both
copied lists receive `0xFF` terminators. The table and all storage retain
their existing owners, and unknown names remain unchanged.
