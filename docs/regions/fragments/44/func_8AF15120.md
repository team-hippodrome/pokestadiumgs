# Type-pair list construction

`func_8AF15120` builds the byte-pair list at `D_8AF33770` for one type
slot and resets its signed-halfword count at `D_8AF33C80`. It scans the
selected row of the 17-by-17 count table `D_8AF33A30` twice. A positive
diagonal entry produces the selected slot's self-pair first. The second
pass appends the remaining positive entries in ascending slot order.
Every pair stores the selected slot followed by the row's column slot.

`func_8AF152A8` fills the symmetric count table by mapping both types of
each species through `func_8AF01530` and incrementing both pair orders.
`func_8AF16064` calls the list builder when selecting a row or opening
its pair list; `func_8AF15954` consumes the list and count to draw the
paired columns. These observations come from inspected source and retail
assembly. The existing function and global names remain unchanged.
