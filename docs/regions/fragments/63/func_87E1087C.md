# Fragment 63 descriptor callback registrations

`func_87E1087C` registers eight callbacks when its second argument is 168.
It reads the root pointer from the first word of its first argument for each
registration. Tags `DGP1` through `DGP4` select `func_87E102D4`; tags `DG_1`
through `DG_4` select `func_87E0F74C`. Each family receives data values 0
through 3. Other values of the second argument leave the descriptors alone.

The existing `func_87E10B30` caller passes a loaded descriptor slot and its
resource ID. `func_87F0AB08` looks up each tag and installs the callback and
data through `func_8004E308`. Its declared callback interface is
`void (*)(s32, u8 *)`.

//@src/fragments/64/fragment64_32D260.c

Two compiler workarounds are labeled `FAKE` in the source. The existing
`func_87E102D4` reconstruction has an integer return type for matching;
the four registrations explicitly cast it to the helper's void callback
interface. Its body is unchanged. An empty block before the final
registration preserves the retail assignment of the callback to `s0` and
the incoming context to `s1`. Without that block, 22 instruction words differ
in their register fields. This block has no functional purpose and is not
claimed to recover original debugging behavior.
