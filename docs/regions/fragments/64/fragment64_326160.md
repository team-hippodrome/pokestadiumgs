`func_80037E3C`, passing its allocated object as callback data. The registrar
stores that pointer at node offset 20. The constructor fills the auxiliary
record reached through object offset 32: position at 4/8/12, optional parent
at 16, word threshold at 20, cached frame at 24, halfword counter at 26 and
mode byte at 28. The three object scale floats are initialized separately.
//@src/fragments/64/fragment64_326160.c
//@src/340C0.c

For graph event 2 on a new `D_80094904` frame, the callback increments the
object's word counter at 28 and the record's halfword counter at 26. Above
the word threshold it calls `func_87F026E8(record->unk_00, object)`, which
clears the active flag and unlinks the item from its owning state. Otherwise
mode 0 adds 127 to the object's signed rotation halfword at 70; mode 1 leaves
it unchanged. The switch preserves the original default behavior too.
//@src/fragments/64/fragment64_324FB0.c

The object position at 72/76/80 is copied from the record, then optionally
increased by the parent's floats at 36/40/44. The existing matrix helper
receives the output at 132, current basis at `D_80094908 + 100`, position,
angles and scale. Every path updates the cached frame. The frame producer is
`GeoRender_AdvanceFrameCounter`; names for unresolved mode meanings remain
unchanged.
//@src/fragments/64/fragment64_328C20.c
//@src/340C0.c

record's carrier. All existing C and data remain unchanged. No unused local,

## func_87F03884 — object construction

null on failure. On success it registers `func_87F03730` with the object as
callback data, resets the model node, and binds the owner's model data for
modes 0 and 1. Both switch cases retain their separate original calls.
`func_8003F114` has its actual void result, two signed-halfword selectors and
model-data pointer; `func_8003F1DC` resets the node through its actual pointer
argument.
//@src/fragments/64/fragment64_324FB0.c
//@src/340C0.c

The constructor stores the auxiliary mode byte, threshold, cached frame,
zero counter, position and optional parent pointer. It copies the position
into the object, adds the parent's position when present, initializes all
three scale floats and stores the signed-halfword rotation. It returns the
allocated object pointer. Existing callers such as `func_86703E9C` pass the
owner, mode, parent, three position floats, rotation, scale and threshold;
they ignore the result. The existing callback consumes the initialized fields.
//@src/fragments/55/fragment55_code.c
