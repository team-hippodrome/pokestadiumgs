## func_84105F10 (accepted 2026-10-28)

`pos += RotateY(velocity, rotation) * scale`. `ParticleMath_RotateVec3fY` takes
the vector and the `s16` rotation triple *by value*; the triple is copied
straight from `D_84190194 + 0x1E` (the `lwl`/`lwr` pair is IDO's 2-aligned struct
copy). Local `ParticleVec3f`/`ParticleVec3s` types describe the by-value
arguments. fragment27's definition spells the same ABI as three
`Frag27FloatBits` words plus a `u16`.
